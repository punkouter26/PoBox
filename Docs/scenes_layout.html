Test • Built-in (build index 0) Assets/Scenes/SCN_TEST_BALANCE_CONTEST.unity
FightersSpawned at runtime (0 baked)

Slot capacity8 ring slots (2 rows of 4)
CameraMain + Drama + Winner

Main Camera

Camera + AudioListener
Default URP camera at ring center; used until the menu hands off to the drama camera.

Directional Light

Light
Single key light, no shadows by default (URP).

Ground

Static collider mesh
The 6.1 m canvas ring floor. Static — qualifies as "ground" for Sensor_GroundContact.

RingRopes

Systems_RingRopes
Spawns the four ropes (M_RopeRed/White/Blue) at ring perimeter on start. Decorative.

Spot0 / Spot1 / Spot2

Lights (URP spot)
Stage spotlights for the menu and contest presentations.

ContestSetupMenu

Systems_ContestSetupMenu (UIDocument)
Opening menu: title chip, version stamp top-left (project rule), two-column slot grid with fighter dropdowns, FIGHT button. Hides itself on start.

ContestSpawner

Systems_ContestSpawner
Reads the menu choices, instantiates the matching prefabs at slot positions, wires behavior parameters, enables the sleeping ContestSystems root.

ContestSystems (disabled until spawn)

Composite root
Wake on first spawn. Contains the referee, FX, cube thrower, announcer, drama camera. Self-discovers fighters in Start.

ContestReferee

Systems_BalanceContest (UIDocument)
Referee UI: title chip, name plates, longest-survives logic, raises RoundEnded/RoundStarted.

ContestAnnouncer

Systems_Announcer
Commentary + audio cues; subscribes to referee and cube events.

CubeThrower

Systems_CubeThrower
Spawns contest cube projectiles aimed at the ring; curriculum-driven (cube_speed_max).

Shover / HazardDirector

Systems_Shover + Systems_HazardDirector
Applies random horizontal impulses (shoves) to alive fighters; shove_force_max curriculum param scales the impulse cap.

MatchDirector

Systems_MatchDirector
Owns overall match flow (best-of-N rounds, hold-restart on decision). Tells referee to stop starting new rounds.

DramaCamera

Systems_DramaCamera (disabled)
Enabled after spawn. Cinematic camera: orbits / zooms onto the standing fighter.

WinnerCamera / CM_WinnerCamera

Systems_WinnerCamera + Cinemachine
Final-shot camera on the last standing fighter; activated by referee on round end.

KnockoutFx / FX_Dust / FX_Confetti

Particle systems
Visual FX: dust on fall, confetti on round end, knockout flash.

CrowdAudio / BannerAudio / ImpactAudio

Systems_CrowdAudio + AudioSources
Audio: crowd loop (CC-BY), banner sting, impact thump. See CREDITS.md for crowd asset attribution.

DebugOverlay

Systems_DebugOverlay
Editor-only FPS counter, reward readout, fall-cause histogram (when enabled).
Runtime flow: menu → spawner picks roster → spawn 0..8 fighters → wake ContestSystems → referee begins round 1 → fall sensors decide winners → match director decides best-of-N.

SCN_TRAIN_BALANCE

Training • Capsule • 16 agents Assets/Scenes/SCN_TRAIN_BALANCE.unity
Fighters16 baked (Fighter_00..Fighter_15)
PrefabFighter_Capsule
RewardReward_Balance (product form)
Env buildBuilds/BoxerBalanceEnv/

Fighter_00 .. Fighter_15

Fighter_Capsule prefab instances
16 active-ragdoll fighters spaced evenly on a circle (training diversity). Each carries Agent_FighterBoxing, BehaviorParameters (BehaviorName="Boxer"), DecisionRequester, Systems_FighterRig, Systems_Stamina, Reward_Balance, ground-contact sensors, and the 14 ConfigurableJoints.
Children: Pelvis (root rigidbody) → Torso → Head/UpperArmL/R/ForearmL/R/GloveL/R; Pelvis → ThighL/R → ShinL/R → FootL/R. All segments are ConfigurableJoint-driven; visual mesh segments share a _vis suffix.

Ground

Static collider
Large static plane; serves as "ground" for all 16 fighters simultaneously.

Academy / DecisionRequester (on each fighter)

Unity.MLAgents components
DecisionRequester ticks the policy every DecisionPeriod fixed steps. PPO collects observations at 50 Hz.
Usage: mlagents-learn Config/BoxerBalance05.yaml --run-id=boxer_balance05 --env Builds/BoxerBalanceEnv/BoxerBalanceEnv.exe --no-graphics --num-envs 4. TensorBoard on results/.

SCN_TRAIN_BALANCE_GRANDMA

Training • Grandma • 16 agents Assets/Scenes/SCN_TRAIN_BALANCE_GRANDMA.unity
Fighters16 baked
PrefabFighter_Grandma (imported skeleton)
RewardReward_Balance (sum form, gen 3 product candidate)
Env buildBuilds/GrandmaBalanceEnv/

Fighter_00 .. Fighter_15

Fighter_Grandma prefab instances
16 Grandma skeletons (imported rigged GLB). Same rig topology as Capsule but with human bone axes — the agent's heuristic Kp/Kd signs are calibrated negative to stabilize these rigs.

Ground

Static collider
Shared plane.
Why a separate scene? Bone axes differ between rigs (capsule vs imported skeletons), so each rig must train its own model line. A Grandma brain cannot drive a Capsule and vice versa.

SCN_TRAIN_LOCOMOTION

Training • Unified stand+walk • 16 agents Assets/Scenes/SCN_TRAIN_LOCOMOTION.unity
Fighters16 baked
PrefabFighter_Capsule with locomotion flag on
RewardReward_Locomotion (product, no fall penalty)
Obs size125 (121 + 4 command)
Env buildBuilds/BoxerLocomotionEnv/

Fighter_00 .. Fighter_15

Fighter_Capsule + Agent_FighterBoxing (locomotion flag)
Each fighter carries Reward_Locomotion instead of Reward_Balance; the commanded speed and direction are added to the observation vector (LOCOMOTION_OBSERVATIONS=4).

Ground

Static collider
Shared plane.
Single-brain design: one brain learns to obey any commanded speed; the game sets 0 m/s for the balance contest and 1 m/s for the walk race at runtime. Curriculum raises speed_command_max from 0 to 1.0.

RewardReward_Balance + Reward_Walk

Contest_Standard / Contest_Grandpa / Contest_Grandma / Contest_Capsule

Fighter prefab instances
4 fighters pre-placed at the start line, each with Reward_Balance + Reward_Walk stacked. Observation vector unchanged from Stage 1 — that is what lets init_path: results/boxer_balance05/Boxer warm-start this run.

Ground + FinishLine

Static collider + trigger
Long lane floor + trigger at the far end as a redundant goal termination.
Skill chain: Stage-1 balance brain (already standing) is fine-tuned for travel along +Z. The -1 fall terminal from Reward_Balance is preserved.
